# FocusLedger · 专注时账

Windows 专注时间记录工具。自动记录学习与工作中的专注时间，支持自定义统计软件和空闲阈值，通过日、周、月、年报表查看时间投入。

## 功能

- **自定义软件**：从运行中的软件或 `.exe` 文件添加统计对象，可单独启用、停用或移除。
- **自动计时**：使用已启用的软件时记录时间，切换到其他软件、暂停或锁屏后停止计时。
- **保留阅读与思考时间**：短暂停顿继续计时，超过空闲阈值后暂停；默认 3 分钟，可为每个软件设置 1–60 分钟。
- **统计与筛选**：提供日、周、月、年报表、投入趋势、软件分布和年度热力图；时间明细支持按软件和时长筛选。
- **补记与导出**：支持补记、编辑、删除记录，以及导出 CSV。
- **本地保存**：数据目录可自定义，支持完整备份与恢复。
- **外观与托盘**：提供森野、晴空、夜航三套主题，支持托盘运行与开机启动。

## 开始使用

需要 Windows x64 和 .NET 10 Windows Desktop Runtime（x64）。

1. 打开程序目录中的 `FocusLedger.exe`。
2. 进入“设置 → 计时与软件”，添加需要统计的软件，调整空闲阈值并保存。
3. 切换到已启用的软件后开始自动计时，在“概览”中查看统计。

“添加运行中的组件”会列出当前可添加的软件，选择后加入列表。找不到目标软件时，可先启动它，或使用“添加 .exe”。

关闭主窗口后，程序继续在托盘中运行。可通过主窗口或托盘暂停、恢复记录；从托盘选择“退出”可完全关闭程序。开机启动默认关闭，可在设置中启用。

## 计时方式

FocusLedger 根据前台软件和键鼠空闲时间估算专注时间。同一时刻只计入一个软件，不会重复累计。

空闲阈值内的时间保留为阅读或思考时间。例如阈值为 3 分钟，10:00 最后操作、10:10 恢复，则保留 10:00–10:03，排除之后的空闲时间。可根据习惯调整默认阈值，也可为每个软件分别设置。

持续静默阅读超过阈值会暂停计时；离开电脑后也可能保留阈值内的时间。后台任务或自动输出本身不会延长计时。多显示器使用时，以当前有焦点的窗口为准。休眠和采样中断期间不补算时间。

统计按软件进程区分，不区分同一软件中的项目、网页或内容。

## 报表与记录

- 选择日、周、月或年查看统计，周一为一周开始；日期按 Windows 本地时区显示。
- 悬停在有投入的趋势柱或年度热力图格子上，可查看对应时间与时长。灰色表示无有效投入记录。
- 时间明细默认显示全部软件中 **不少于 1 分钟** 的记录，可修改软件和最短时长筛选。筛选只影响明细，不改变汇总、图表或 CSV 导出。
- 明细标题显示“筛选后数量/总数量 段”，列表最多显示符合条件的最近 1000 段。CSV 包含当前周期全部有效记录。
- 使用“补记时间”添加遗漏的时间；与已有记录重叠的部分会被替换，避免重复统计。不能补记未来时间。
- 编辑和删除针对整段记录，包括跨越日期边界的片段。操作暂不支持在界面中撤销，建议修改前备份。

## 数据与隐私

默认将记录和设置保存到 **`FocusLedger.exe` 所在目录下的 `data` 文件夹**。可在“设置 → 数据与启动”更换位置；默认目录不可写时，程序会提示选择其他目录。

选择空目录后，现有记录与设置会复制过去，原目录保留为副本。选择已有记录的目录时，会先询问是否使用其中的数据，两处记录不会自动合并。

程序正常使用无需联网，不保存输入内容、鼠标坐标、窗口标题、聊天正文或截图。只保存有效的自动记录和人工补记，不统计程序自身的运行时长。

### 备份与恢复

在“备份数据”中选择目标目录并点击“创建完整备份”，每次备份都会生成独立文件夹，包含记录和设置。

恢复时，在“设置 → 数据与启动”选择备份文件夹，确认使用已有数据。建议先将备份复制到日常使用的数据目录，再切换到该位置。

### 更新程序

先从托盘退出程序，再替换程序文件。保留 `data` 文件夹和 `focusledger.location.json`；使用自定义数据目录时也应保留其中的文件。

## 从源码构建

需要 Windows x64 与 .NET 10 SDK。在项目根目录运行：

```powershell
# 首次构建：下载依赖、执行测试并发布
.\build.ps1 -Restore -Test -Publish

# 已还原依赖后构建
.\build.ps1 -Test -Publish
```

输出位于 `publish` 文件夹，运行 `publish\FocusLedger.exe` 即可。
